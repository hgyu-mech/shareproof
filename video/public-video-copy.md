ShareProof | Inspect the screenshot you share — working browser demo

# Public video description

ShareProof suggests email and phone regions with local English OCR, supports manual covers, and inspects those covers in the final exported PNG. This 2:20 demo shows actual browser interaction states captured and edited into a silent sequence. The receipt is an original synthetic sample.

The demonstrated PNG passed an exact opaque-pixel check across 27,480 selected pixels. The file hash links it to a review note. An edit invalidates the previous inspection.

The check applies to selected regions. OCR can miss details; manual review remains necessary. It does not certify complete anonymization.

The source repository includes project scope, requirements, specification and 12 passing core checks. Tesseract.js and its pretrained model retain their own licenses.
