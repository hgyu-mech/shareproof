# Build checklist
- [ ] First slice implemented and tested: masks → PNG decode → pixel inspection.
- [ ] Second slice implemented and tested: real OCR suggestions and explicit review choices.
- [ ] Invalid-file / OCR-failure / pending-review / stale-export states checked.
- [ ] Desktop, tablet and phone visual QA.
- [ ] Source and public artifact privacy audit.
- [ ] Participant reviewed the working product; authentic feedback saved.
- [ ] Demo footage shows actual working app, under three minutes.
- [ ] Public repository with scope/PRD/spec, license and setup instructions.
- [ ] Public video and final submission consent.

Public description and reflection will describe only actual work and feedback. No fabricated customer use, time savings, performance percentages or independent human coding.
